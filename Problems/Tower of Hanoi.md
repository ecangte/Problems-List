## **河內塔** ***Tower of Hanoi*** 

`time limit` 1s
`memory limit` 256MB

### ***Statement***

河內塔是一個經典的演算法題目，經常作為遞迴演算法的入門。遊戲規則是有三根杆子 A、B、C，一開始 A 杆子上有 N 個中間穿孔的盤子，每個盤子由上到下由小變大。遊戲的目標是，在每次只能移動一個盤子的情況下，並且大盤不能放在小盤上，將所有的盤子放到 C 杆上。

但是心地善良的 ecangte 考慮到大家沒學過遞迴，不會寫這題，所以決定改變題目。

已知如果一個河內塔有 $n$ 個盤子，達成目標所需要的最小步數為 $2^n-1$ 個，寫成函數就是：

$$
H(n) = 2^n-1
$$

題目會輸入 $n$ 個盤子的最少步數，請你輸出 $n$ 的值（必定能求出 $n$ 的值）。


### ***Input***

$H(n)$


### ***Output***

$n$

### ***Sample Input 1***

```
7
```

### ***Sample Output 1***

```
3
```

### ***Sample Input 2***

```
65535
```

### ***Sample Output 2***

```
16
```

### ***Note***

* $1 \le H(n) \le 10^{18}$
* 所有輸入數值皆為整數
