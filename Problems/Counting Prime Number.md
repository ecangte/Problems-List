質數，指只能被1和自己本身以外，不能被其他正整數整除且大於1的正整數。

普奇神父在慌亂時，會開始一邊數質數，一邊思考問題、分析狀況，數質數也往往被視為普奇神父比較有代表性的行為。神父數得很熟練，雖然數錯過。

你可以寫一個程式判斷普奇有沒有數錯質數嗎？

已知普奇數了 $N$ 個整數，分別是 $A_1, A_2, \dots, A_{N-1}, A_N$ ，如果普奇數的全部都是質數，就輸出 `"Correct"` ，反之輸出 `"Incorrect"` （你只需要判斷是否全部都是質數，不需要判斷有沒有多數少數，也不需要判斷有沒有照順序數。）

### ***Input***

$N$  
$A_1, A_2, \dots, A_{N-1}, A_N$

### ***Output***

$Ans$

### ***Sample Input 1***

```
8
2 3 5 7 11 17 19 23
```

### ***Sample Output 1***

```
Correct
```

### ***Sample Input 2***

```
13
6 7 6 7 6 7 6 7 6 7 6 7 67
```

### ***Sample Output 2***

```
Incorrect
```

### ***Note***

* $1 \le N, A_i \le 10^7$
* 所有輸入數值皆為整數

### ***Subtask***

- ***subtask1***: $5\\%$ $1 \le N, A_i \le 100$
- ***subtask2***: $19\\%$ $1 \le N, A_i \le 5000$
- ***subtask3***: $31\\%$ $1 \le N, A_i \le 2 \times 10^4$
- ***subtask4***: $45\\%$ ***As statement***
