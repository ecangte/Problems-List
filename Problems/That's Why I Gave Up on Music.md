接觸了這首歌的你，被交織的音樂深深吸引著，對於故事中兩名主角 **Amy（エイミー）** 和 **Elma（エルマ）** ，你決定挖掘他們之間的故事。你翻遍了整張專輯，從歌詞中看見了一句話：

> エルマ、君なんだよ  
> 君だけが僕の音楽なんだ
>
> Elma，就只有你啊  
> 只有你才是我的音樂啊
>
> —— ヨルシカ〈藍二乗〉

「究竟音樂為何物。」你不盡產生了這樣的想法。為此，你決定了解透徹音樂的本質。

根據古典音樂家的描述，他們將 **C** 到 **高八度的 C** 之間平均分 12 等分，並稱其為 ——「**十二平均律**」。

並且將這 12 個音每個給一個音名，依序如下：

$$ C,\ C♯,\ D,\ D♯,\ E,\ F,\ F♯,\ G,\ G♯,\ A,\ A♯,\ B$$
$$ $$

這12個音會繼續接到 C 無限輪迴下去，也就是說：

$$\dots,\ A♯,\ B,\ C,\ C♯,\ D,\ D♯,\ E,\ F,\ F♯,\ G,\ G♯,\ A,\ A♯,\ B,\ C,\ C♯,\ \dots$$
$$ $$

音跟音之間有距離單位，最小的距離單位稱為
 **半音（例如：$A \rightarrow A♯$）**。還有其他的距離單位像是 **大三度**（兩個音的距離為4個半音，例如：$C \rightarrow E$），和 **小三度**（兩個音的距離為3個半音，例如：$D \rightarrow F$）

接著你又學到另一個東西 ——「**和弦**」。

根據定義，由三個音以上同時演奏稱為和弦，如果只有三個音，則稱為 **三和弦**，和弦中最低的那個音則稱為 **根音**。三和弦總共分為以下 4 種：

1. **大三和弦（Major）**，根音到第 2 個音的距離為 **大三度**，第 2 音到第 3 音的距離為 **小三度**。
2. **小三和弦（Minor）**，根音到第 2 個音的距離為 **小三度**，第 2 音到第 3 音的距離為 **大三度**。
3. **增三和弦（Augmented）**，根音到第 2 個音的距離為 **大三度**，第 2 音到第 3 音的距離為 **大三度**。
4. **減三和弦（Diminished）**，根音到第 2 個音的距離為 **小三度**，第 2 音到第 3 音的距離為 **小三度**。

接下來輸入有一行，輸入三個字串 $R, T, F$（保證 $R$ 比 $T$ 低，$T$ 比 $F$ 低，不會輸入任何不符合題意的字串，並保證一定能選出答案。）請你輸出這個和弦是 Major、Minor、Augmented 還是 Diminished。

為了方便輸入，我們將輸入中的升記號全部改為 # (井字號)。

### ***Input***

$R, T, F$

### ***Output***

$Major, Minor, Augmented\ or\ Diminished$

### ***Sample Input 1***

```
C E G
```

### ***Sample Output 1***

```
Major
```

### ***Sample Input 2***

```
A C D#
```

### ***Sample Output 2***

```
Diminished
```
