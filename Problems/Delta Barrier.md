## **三角結界** ***Delta Barrier*** 

`time limit` 1s
`memory limit` 256MB

### ***Statement***

你的名字是 **白井黑子**，是學園都市常盤台中學的學生，同時也是第177分部的風紀委員，今天你也一樣做著風紀委員的任務。

此時你收到 **初春飾利** 的消息，在前方轉角路口處有三名不良少年在勒索學生，而正義感十足的你決定制服這三名不良少年。你身為學園都市的 Level 4 能力者，制服他們可以說是輕而易舉。這時，他們突然擺出 **三角結界（Delta Barrier）** 抵禦你的攻擊。**初春飾利** 根據他頂尖駭客技術查到的資料，指出這是學園都市高層製作出的最新的防禦招式，原理是將AIM擴散立場融合成一個完美的 **三角形** 來抵禦攻擊。陷入苦戰的你正不知如何是好時，**佐天淚子**找到（在都市傳說網站上看到）這個結界的破解方法。方法如下：

1. 將三角形拆成 $a, b, c$ 三邊。
2. 如果 $a, b, c$ 其中的 **任兩數之和** 皆 $>$ 第三數，則此結界不可能被破解。
3. 如果 $a, b, c$ 其中有 **任兩數之和** $\le$ 第三數，你需要 $D(a, b, c)\ mod\ 10^9 + 7$  焦耳 的能量才能破解。令 $S = a + b + c, P = 10^9 + 7$ 。$D(a, b, c)$ 的定義如下：

$$
D(a, b, c) = \frac{S^S \times P}{S^{a + b} + S^{a + c} + S^{b + c}}
$$

當你得知這個資訊後，你深知破解此結界的唯一方法就是呼叫 Level 5 的電擊能力使 **御坂美琴**。如果此結界不可能被破解就撤退，可被破解就請你計算出需要幾焦耳的能量，以便 **御坂美琴** 發射 **超電磁砲**。

一開始會輸入三個整數 $a, b, c$ 代表 **三角結界** 的三邊長（必可以組成三角形）

如果此結界可以被破解，請輸出 "Yes" 並輸出要多少焦耳的能量，中間隔一空格。反之輸出 "No"。

### ***Input***

$a, b, c$ 

### ***Output***

$Ans$

### ***Sample Input***

```
3 4 5
```

### ***Sample Output***

```
No
```

因為 $3 + 4 > 5$ 並且 $3 + 5 > 4$ 並且 $4 + 5 > 3$ ，因此此結界不可能被破解。

### ***Note***

* $1 \le a, b, c \le 10^9$
* 所有輸入數值皆為整數
