## 題目難度列表

這裡我會將題目難度由簡單到困難 1 ~ 10 打分，

* $1:$ 最簡單只有最基本語法的題目
* $2, 3:$ 基本語法活用題（大概 APCS 初級）
* $4, 5:$ 二維陣列等等的應用，還不涉及複雜演算法（大概 APCS 中級）
* $6, 7:$ 涉及二分搜、貪心、遞迴等初級演算法（大概 APCS 中高級）
* $8:$ 運用到動態規劃、圖論、線段樹等較難的演算法（大概 APCS 高級）
* $9, 10$ 學科全國賽、IOI難度的題目（應該不會出，出了我也不會 QAQ）
